MawyA Markdown viewer and editor in one, made to embed

A light, fast graphical viewer and editor, so reading or writing a Markdown document takes nothing else. Put it in a code editor, a documentation page or an AI application. It embeds in more than one language and environment.

It goes wherever Markdown is shown

A code editor, a documentation page, an AI application. It draws inside a page that already has styles of its own without mixing with them, and the same library goes into React and into Flutter.

The viewer and the editor are one

The surface that writes a document and the surface that reads it share a parser and a renderer. What a reader sees is what the author had in front of them, down to the line breaks.

The editor

Reading only? Take the viewer alone

A screen with nothing to edit gets the viewer on its own. The toolbar, the theme and the font settings come with it, and the document is drawn exactly as the editor drew it.

The viewer

Nothing to assemble first

One package and one line of CSS. There is no theme file to fill in, no build-side plugin, and no second library to render what you wrote.

Getting started

Key features ​

  • Viewer and editor in one package
  • WYSIWYG and Markdown source, either way round
  • React and Flutter on the same parser
  • CommonMark and GitHub's extensions
  • Dark mode and typography built in
  • English and Korean interface included
  • Rendering that stays out of your page's styles
  • Directives for syntax it does not know
