어디에나 탑재됩니다

코드 에디터, 문서 페이지, AI 애플리케이션처럼 마크다운을 보여줄 자리라면 어디든 들어갑니다. 페이지가 이미 갖고 있는 스타일과 섞이지 않고, React와 Flutter 두 환경에 같은 라이브러리로 올라갑니다.

뷰어와 에디터가 하나입니다

문서를 고치는 화면과 읽는 화면이 같은 파서와 같은 렌더러를 씁니다. 작성자가 보던 화면과 독자가 보는 화면이 줄바꿈 하나까지 같습니다.

에디터

읽기만 하는 자리에는 뷰어만

편집이 필요 없는 화면에는 뷰어만 올리면 됩니다. 툴바와 테마, 글꼴 설정이 그대로 따라오고 문서는 에디터에서 보던 모습 그대로 그려집니다.

뷰어

미리 조립할 것이 없습니다

패키지 하나와 CSS 한 줄이면 됩니다. 테마 파일을 채우거나 빌드에 플러그인을 더하거나 렌더링용 라이브러리를 따로 설치할 필요가 없습니다.
