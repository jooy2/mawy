타입 ​

패키지가 내보내는 타입을 하나에 한 페이지씩 담았습니다.

mawy-react와 mawy-react/types 양쪽에서 내보냅니다. 두 번째 진입점은 컴포넌트를 import하지 않고 자기 props에 이 이름들을 쓰려는 애플리케이션을 위해 있습니다.

package:mawy/mawy.dart에서 내보내고, 그것이 이 패키지의 공개 표면 전부입니다. import 하나면 다 됩니다.

에디터와 뷰어 ​

페이지다루는 것
에디터 화면문서를 어느 화면으로 보여 줄지.
MawyEditorToolbarItem에디터 툴바의 컨트롤 하나와 고르는 방법.
MawyEditorStatusItem에디터가 아래쪽 가장자리에서 세는 것.
MawyViewerToolbarItem뷰어 툴바의 컨트롤 하나와 고르는 방법.
프레임표면이 테두리를 두를지, 툴바가 어느 끝에 있을지.
MawyColorScheme어느 팔레트로 그릴지.
MawyLocale인터페이스가 쓰는 언어. 문서의 언어가 아닙니다.

문서 읽기 ​

페이지다루는 것
MawyParseOptions마크다운 자체를 어떻게 읽을지.
MawyQuotes활자 옵션을 켰을 때 따옴표를 그릴 네 기호.
MdDocument파싱한 문서와 그 아래 모든 노드.
MawyUrlResolver문서의 상대 URL이 어디를 가리키는지.
링크와 이미지 그리기링크를 따라가거나 그림을 내려받게 두지 않을 때 둘을 어떻게 그릴지.
MawyDirectiveKind디렉티브가 세 모양 중 어느 것으로 쓰였는지.
디렉티브이 패키지가 모르는 구성물을 무엇으로 그릴지.
MawyHighlighter코드 블록에 마크업이 아니라 토큰으로 색을 입히는 것.
이미지그림이 무엇이 되는지, 에디터에 넣은 그림이 어디로 가는지.
페이지다루는 것
MawyHtmlPolicy문서 안에 쓰인 날 HTML을 어떻게 할지.
MawyLinkTarget문서가 쓴 링크가 어디에서 열릴지.
MawyLinkRel그 링크가 가는 곳에 대해 무엇을 밝힐지.
MawyRange문서의 한 조각이 쓰인 자리를 두 수로.
