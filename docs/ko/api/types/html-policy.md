# `MawyHtmlPolicy`

문서 안에 쓰인 날 HTML을 어떻게 할지.

::: fw flutter

이것은 React 패키지의 것입니다. 여기서 문서 안의 날 HTML은 쓰인 글자 그대로 보이고, 이를 바꿀 방법은 없습니다. 그것을 그릴 HTML이 Flutter에는 없기 때문입니다. 두 패키지가 문서를 두고 달라지는 유일한 지점이고, 그 차이는 문서가 말하는 바가 아니라 화면이 할 수 있는 일에 있습니다.

:::

::: fw react

```ts
type MawyHtmlPolicy = 'escape' | 'sanitize' | 'raw';
```

- `'escape'` — 쓰인 글자 그대로 보입니다. 기본값이고, 단서 없이 안전한 유일한 값입니다.
- `'sanitize'` — 그립니다. 엘리먼트와 속성, URL 스킴의 허용 목록 밖에 있는 것을 먼저 걷어냅니다.
- `'raw'` — 쓰인 그대로 그립니다. 걷어내는 것도 검사하는 것도 없습니다. 문서의 `<script>`가 실행되고, 이미지의 `onerror`가 실행되고, `<iframe>`이 로드됩니다. 페이지 자신의 출처로, 페이지 자신의 쿠키를 가지고. **문서에 글자를 넣을 수 있는 사람은 애플리케이션이 할 수 있는 일을 무엇이든 할 수 있습니다.** 애플리케이션이 직접 쓴 문서나 이미 스스로 안전하게 만든 문서에만 쓰세요.

셋 중 무엇도 링크에는 영향을 주지 않습니다. `[click](javascript:…)`은 어느 값에서도 거절됩니다. 그것은 HTML이 아니라 마크다운이고, HTML 정책을 바꾼 것이 그에 대한 진술이었던 적은 없기 때문입니다. [안전](../../guide/viewer#안전)을 보세요.

:::
