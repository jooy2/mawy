# `MawyViewerAnchors`

그려진 문서의 블록이 그것을 스크롤하는 상자 안 어디에 놓였는지.

::: fw react

이것은 Flutter 패키지의 것입니다. 브라우저는 같은 물음에 엘리먼트의 경계 상자를 읽어 답하고, 뷰어가 그리는 모든 블록이 바로 그 용도로 `data-mawy-range`를 지니고 있습니다. [원문 위치 추적](../../guide/viewer#원문-위치-추적)을 보세요.

:::

::: fw flutter

```dart
class MawyViewerAnchors {
  MawyViewerAnchors();

  /// 모든 블록을, 그것이 시작하는 글자 위치와 그 블록을 화면 맨 위에 둘
  /// 스크롤 오프셋의 쌍으로.
  List<(int, double)> places();
}
```

뷰어는 바깥에서 알아낼 수 없는 두 가지를 압니다. 각 블록이 원문의 어느 글자에서 왔는지, 그리고 그 블록이 화면 어디에 놓였는지입니다. 그려진 문서에 다른 뷰를 맞춰 세우는 것은 둘 다 수로 필요하고, 에디터의 `split`이 이 기능이 존재하는 이유입니다.

[`MawyViewer`](../components/mawy-viewer#배치와-스크롤)에 하나 건네고 `places()`로 물으면 됩니다. 답은 문서 순서대로 나오고, 화면에 보이는 블록만이 아니라 모든 블록이 답합니다. 뷰어가 이미 배치한 블록은 정확한 값이고, 아직 배치하지 않은 블록은 다른 블록이 잰 값에서 계산한 값이라 겨냥할 자리였다가 그려지는 순간 정확해집니다.

답은 블록마다 레이아웃을 읽어서가 아니라 뷰어가 스스로 기록해 둔 블록 높이에서 나옵니다. 그래서 묻는 일은 산술이고, 포인터가 코드 블록 위를 지나가서 다시 그려지는 뷰어는 아무것도 재지 않습니다.

:::
