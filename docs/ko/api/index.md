# API

패키지가 내보내는 전부입니다. 각 항목은 그것이 무엇이고, 무엇을 받고, 무엇을 돌려주는지를 적습니다.

::: warning 초기 단계입니다

컴포넌트는 만들어지는 중이고 아직 여기에 없습니다. 아래가 현재 패키지의 공개 표면 전부입니다.

:::

## 타입

`mawy`와 `mawy/types` 양쪽에서 가져올 수 있습니다. 두 번째 진입점은 컴포넌트를 import하지 않고도 애플리케이션의 props에 이 타입들을 쓸 수 있게 하기 위한 것입니다.

### `MawyMode`

```ts
type MawyMode = 'wysiwyg' | 'plain' | 'preview';
```

문서를 어느 화면으로 보여줄지. 세 가지는 세 개의 에디터가 아니라 하나의 문서를 보는 세 화면입니다 — [에디터](../guide/editor) 참고.

- `'wysiwyg'` — 그려진 문서를 그 자리에서 편집.
- `'plain'` — 마크다운 원문을 텍스트로 편집.
- `'preview'` — 그려진 문서, 읽기 전용.

### `MawyColorScheme`

```ts
type MawyColorScheme = 'light' | 'dark' | 'system';
```

어느 팔레트로 그릴지. `system`은 `prefers-color-scheme`를 따르며 기본값입니다. 그 질의에 이미 답하고 있는 애플리케이션 안에 들어간 에디터가 어두운 페이지 위의 흰 사각형 하나가 되어서는 안 되기 때문입니다.

### `MawyLocale`

```ts
type MawyLocale = 'en' | 'ko';
```

에디터 UI 자체의 언어 — 툴바 라벨, 메뉴 항목, 스크린 리더에게 전달되는 텍스트. 문서가 어떤 언어로 쓰였는지와는 무관합니다.

## 스타일시트

### `mawy/styles.css`

완성된 스타일시트이며, 애플리케이션이 한 번 import합니다. 라이브러리가 그리는 모든 값은 `--mawy-*` 커스텀 속성이고, 그 이름 공간이 테마를 위해 지원되는 표면의 전부입니다. 토큰은 상속되므로 바깥 요소에 한 번 선언하면 그 안의 모든 Mawy 화면에 닿습니다.

## 컴포넌트

아직 없습니다. `MawyEditor`와 `MawyViewer`가 첫 릴리스와 함께 들어옵니다. 무엇을 목표로 만들어지고 있는지는 [에디터](../guide/editor)와 [뷰어](../guide/viewer)에 적혀 있습니다.
