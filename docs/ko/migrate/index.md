# 다른 에디터에서 옮겨오기

쓰던 마크다운 에디터를 Mawy로 바꾸려면 무엇을 해야 하는지, 그리고 이미 쌓아 둔 문서는 어떻게 되는지 적었습니다.

여기 나오는 에디터는 결국 같은 것을 저장합니다. 데이터베이스 어딘가에 들어 있는 마크다운 문자열입니다. Mawy는 그 문자열을 `value`로 받고 `onChange`로 돌려주므로, 옮기는 일의 대부분은 변환이 아니라 배선입니다. 문자열이 어디서 오고 어디로 가는지, 그리고 쓰던 옵션이 여기서는 무슨 이름인지를 맞추면 됩니다.

| 쓰던 것 | 패키지 | 문서 |
| --- | --- | --- |
| Toast UI Editor | `@toast-ui/editor`, `@toast-ui/react-editor` | [Toast UI Editor에서](./toast-ui-editor) |
| MDXEditor | `@mdxeditor/editor` | [MDXEditor에서](./mdxeditor) |
| Milkdown | `@milkdown/kit`, `@milkdown/crepe` | [Milkdown에서](./milkdown) |
| react-md-editor | `@uiw/react-md-editor` | [react-md-editor에서](./react-md-editor) |

::: fw flutter

전부 웹 라이브러리이므로 Flutter 애플리케이션 안에서 옮겨올 것은 없습니다. 이 문서가 이 패키지에서 쓸모 있는 경우는 하나입니다. 문서를 브라우저에서 쓰고 앱에서 읽는 애플리케이션입니다. 파서가 두 패키지에서 같고 변경마다 서로 diff하므로, 저 에디터들에서 옮겨온 문서는 쓰인 페이지에서 읽히던 대로 휴대폰에서도 읽힙니다.

:::

## 네 경우 모두 같은 순서

1. **쓰던 에디터 자리에 `MawyEditor`를 둡니다.** 인스턴스와 ref 대신 `value`와 `onChange`를 씁니다. [에디터](../guide/editor)에 있습니다.
2. **완성된 문서를 그리던 코드를 [`MawyViewer`](../api/components/mawy-viewer)로 바꿉니다.** 자바스크립트를 내려보내지 않을 페이지라면 [`MawyDocument`](../api/components/mawy-document)입니다. 애플리케이션에는 대개 이런 화면이 하나쯤 있고, 대개 잊힙니다.
3. **`mawy-react/styles.css`를 한 번 가져오고** 쓰던 에디터의 스타일시트를 지웁니다. 그 클래스 이름에 덮어쓴 CSS도 함께 나갑니다. 여기서 테마는 [`--mawy-*` 토큰 재선언](../api/theming)입니다.
4. **옵션을 옮깁니다.** 각 문서의 대응표를 보세요. 대부분은 여기 이름이 있고, 없는 것은 직접 찾게 두지 않고 적어 두었습니다.
5. **실제 문서 몇 개를 열어 그대로 저장한 뒤 diff합니다.** 문서를 고쳐 쓰는 에디터는 여기서 드러납니다. 쓰던 에디터를 걷어내기 전에 해 보는 편이 낫습니다.

## 문서에 무슨 일이 생기는가

**아무 일도 생기지 않습니다.** Mawy는 마크다운 문자열 자체를 편집하므로, 그대로 열린 문서는 그대로 저장됩니다. 목록 기호도, 강조 문자도, 빈 줄도 그대로입니다. 무언가를 정규화할 직렬화기가 패키지 안에 없고, 원문과 그려진 문서 사이를 오갈 때도 변환 없이 다른 화면을 마운트할 뿐입니다.

이미 벌어진 일은 다른 이야기입니다. 모델을 들고 있다가 마크다운을 써내는 에디터는 저장할 때마다 문서를 다시 썼고, 데이터베이스에 있는 문서는 그 에디터가 남긴 모양입니다. 읽는 내용은 같고 유효한 마크다운인 것도 맞습니다. 다만 작성자가 친 텍스트는 아닙니다. 여기서 되돌릴 방법은 없고, 대신 여기서 다시 그런 일이 생기지도 않습니다.

## 목록에 없는 에디터라면

위의 다섯 단계가 전부이고, 각 문서는 대응표만 다릅니다. 목록에 없는 에디터라면 두 가지를 먼저 확인하세요.

- **마크다운을 저장하기는 하는지.** ProseMirror 문서나 Lexical 상태, BlockNote의 블록처럼 자체 JSON을 저장하는 에디터라면 모든 행을 그 에디터의 내보내기로 한 번 마크다운으로 바꿔야 합니다. 쓰던 에디터가 아직 설치되어 있을 때 하세요. 걷어내고 나면 그 행을 읽을 수 있는 것이 사라집니다.
- **그 내보내기가 문서를 어떻게 바꾸는지.** 실제 문서 몇 개를 통과시키고 결과를 읽어 보세요. BlockNote의 메서드 이름이 `blocksToMarkdownLossy`인 데는 이유가 있고, 한 방향뿐인 변환은 그것이 유일한 사본이 되기 전에 대가를 알아 두는 편이 낫습니다.
